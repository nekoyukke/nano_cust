# nano_cust for VS Code

`.nc` ファイルに nano_cust のシンタックスハイライト、括弧の補完、`//` コメント入力を提供します。

## ハイライト対象

- `class` / `sprite` / `fn` の宣言と名前
- 変数・引数の宣言、型注釈、クラス型
- 制御構文、オブジェクト操作、リスト操作
- Scratch の組み込み関数、任意の関数呼び出し、メンバー参照
- 文字列、エスケープ、数値、定数、論理・比較・代入・算術演算子

テーマに標準の TextMate スコープを提供するため、VS Code の Dark+、Light+、GitHub 系テーマなどで役割ごとに自然な色分けになります。

## 構文・型チェック

`.nc` ファイルを開くと、拡張機能はワークスペース直下の `main.py` を `--check` 付きで実行します。構文エラーと型エラーは、VS Code の波線と「問題」パネルに表示されます。

- 入力を止めてから 500 ms 後に自動チェックします。
- 保存時には直ちに再チェックします。
- コマンドパレットの **nano_cust: 構文・型をチェック** から手動実行もできます。
- `main.py` がワークスペース直下にない場合は、`nanoCust.compilerPath` にそのパスを設定してください。

## ローカルで試す

1. VS Code でこの `vscode-nano-cust` フォルダを開きます。
2. `F5` を押して **Extension Development Host** を開きます。
3. そのウィンドウで `.nc` ファイルを開きます。

配布する場合は VS Code 拡張機能のパッケージングツールで `.vsix` を作成できます。
